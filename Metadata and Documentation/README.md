### Metadata
**Title:** Integrated Airbnb-Zillow-Census ZIP Code Dataset

**Creators:** Jiya Chachan and Hannah Adachi

**Description:** This dataset integrates Airbnb listing data, Zillow Home Value Index (ZHVI) data, and U.S. Census ZCTA geographic boundaries to analyze spatial relationships between short-term rental activity and housing prices in Los Angeles. The integration includes spatial joins between Airbnb listing coordinates and ZCTA polygons, aggregation of listings into ZIP-level summaries, filtering and formatting of Zillow ZIP-level price indicators, and classification of neighborhoods based on Airbnb density. The resulting dataset supports research into how Airbnb activity correlates with local housing market conditions.

**Version:** 1.0 (Generated 2025-11-1)

**Keywords:** Airbnb, ZHVI, Zillow, Census, ZCTA, Housing Prices, Geospatial Analysis, Spatial Join, IS 477

**Funding/Context:** Created as part of the University of Illinois at Urbana-Chapmaign IS 477 Final Project

**Format:** CSV (`merged_airbnb_zillow_by_zip.csv`); Automatically generated by `data_integration.py`
